# Inbox

Drop copy-pasted job postings here as `.txt` or `.md` files. One posting per file. The
filename does not matter — the recruiter reads the contents.

Use this for postings behind a login (LinkedIn, Workday, company ATS) that cannot be fetched
from a URL.

**This is often the highest-yield intake door in the whole system.** The best leads in a
search frequently arrive this way, from the seeker's logged-in LinkedIn feed. No agent can see
that feed, so anything dropped here is a priority.

## What to include

**Most important: the external apply link.** If the post has an "Apply on company site" button
pointing at Greenhouse, Lever, Ashby, Workday, or a company careers page, paste that URL.
Those destination pages are usually public and fetchable, and the employer's exact wording
lives there.

This is not a formality. The required-vs-preferred distinction that usually decides the
verdict lives in the employer's precise language, and a pasted human summary almost always
loses it. Paste the full posting text verbatim when you can, plus the apply link.

## What happens next

The recruiter sweeps this folder, qualifies each posting against `../../candidate/profile.md`,
and for anything that clears the bar creates an application folder. Processed files get moved
into the folder they produced (or deleted with a recorded reason). The inbox is kept clean.
